# Stankoff 2
Официальная программа для работы со станками от фирмы Stank.
## Описание
Проверяет работоспособность станка, состояние товара и автоматизирует работу со станками.
## Инструкция по установке
1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/faybit/PractWork1.git
   ```
2. Собрать проект
   ```bash
   gcc stankoff2.c -o stankoff2
    ```
 3. Переносим файлы на кассету 
## Использование
1. Вставляем кассету в специальный порт сбоку станка
2. Нажать кнопку старт 3 раза на кассете
## Системные требования
- Видеокарта: GTX 780
- Процессор: Intel Pentium G2020
- ОЗУ: 1 ГБ
- OC: Windows XP
- Место на диске: 200 МБ
